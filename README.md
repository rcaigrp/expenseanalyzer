# ExpenseAnalyzer

A spending trend analyzer and report generator.

## Goal
Analyze spending trends and generate reports.

## Acceptance Criteria
1. `analyzer` module exists and can be imported.
2. `analyze_spending_trends` function returns trend data.
3. `generate_report` function returns a formatted string summary.
4. `filter_by_date_range` returns expenses within a specific date range.
