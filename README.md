# ExpenseAnalyzer

Analyze spending trends and generate reports.

## Goal
Analyze spending trends and generate reports.

## Acceptance Criteria
1. `analyzer` module exists and can be imported.
2. `analyze_spending_trends` returns a dict of spending by time period.
3. `generate_report` returns a string summary of spending.
4. `get_top_categories` returns a list of top N categories by spending.
